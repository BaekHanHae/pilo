# PILO name and identity

PILO is the project's umbrella name. MIT applies to PILO-owned code and documentation; this page does not reduce the permissions granted by MIT.

Use the name accurately when referring to this project. Clearly identify modified distributions and avoid implying that a fork or service is maintained or endorsed by the original project when it is not. No logo is included in this candidate. Domain/name/trademark availability has not been cleared, and no registered-trademark status is claimed.

Potential future module names are organizational ideas, not shipped products. Maintain a coherent local-first, evidence-preserving identity as capabilities are added. Brand assets and a more detailed usage policy can be reviewed before publication.
